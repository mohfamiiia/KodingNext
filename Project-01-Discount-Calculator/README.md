# Project 01 – Discount Calculator

## Description

Discount Calculator is a simple Python application designed to calculate the final price of a product after applying a discount.

This project demonstrates basic Python programming concepts, including variables, user input, mathematical operations, and conditional statements.

## Features

- Input the original product price.
- Input the discount percentage.
- Calculate the discount amount.
- Display the final price after discount.

## Technologies

- Python 3

## How to Run

1. Make sure Python 3 is installed.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

## Learning Objectives

- Understand Python fundamentals.
- Practice user input and output.
- Apply mathematical calculations.
- Use conditional logic.
