# Project 02 – Personal Portfolio Website

## Description

This project is a personal portfolio website designed to introduce my background, showcase selected projects, and highlight my interest in technology and education.

The website uses a natural, modern, and minimalist visual style with green and warm neutral colors.

## Features

- Responsive navigation menu.
- Hero section introducing the portfolio.
- Project showcase section.
- About section.
- Skills and technology overview.
- Responsive layout for different screen sizes.

## Technologies

- HTML5 – Website structure.
- CSS3 – Styling, layout, and responsive design.
- JavaScript – Interactive navigation and dynamic content.

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Run the website using Live Server, or open the HTML file directly in a web browser.
